# 📄 AI Resume Analyzer

This project analyzes resumes and provides:
- Extracted skills
- ATS score
- Suggestions for improvement
- Skills visualization (pie chart)

## 🚀 Features
- Upload PDF resume
- Automatic skill detection
- ATS scoring
- Visual charts

## 🛠️ Tech Stack
- Python
- Streamlit
- pdfplumber
- matplotlib

## ▶️ Run Locally
pip install -r requirements.txt
streamlit run app.py
